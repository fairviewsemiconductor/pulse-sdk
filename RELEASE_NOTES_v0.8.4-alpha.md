# PULSE SDK v0.8.4-alpha

Host runtime bring-up. This document describes current scope.

## This release

- Host ISA packers (A1 DMA, B1 MMA)
- Language bindings: C, C++, Python, Rust, Go
- GRID=4 host golden (16 PEs)
- Wrapper smoke tests via `SDK/pulse/run_all_tests.sh`

## Not in this release

Items that appeared in earlier drafts as delivered silicon features
(HBM4 bandwidth, CUDA-class stack, 144-MEU hardware) are roadmap and
are not part of this release.
